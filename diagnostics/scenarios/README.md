# Диагностические сценарии

Сценарии должны быть привязаны к модели объекта и существующему диагностическому ядру.

Начальные виртуальные сценарии для пилота:
1. Срабатывание групповой защиты.
2. Перегрев аппарата или соединения.
3. Отклонение параметров электроснабжения.

Для каждого сценария фиксировать: симптомы, гипотезы, требуемые данные, возможные проверки, приборы и их профили, ограничения SafetyGateway, критерии достаточности модели, критерии интерпретации результатов и основания заключения.

Не представлять виртуальные сценарии как подтверждённые инструкции для реального электрощита.
