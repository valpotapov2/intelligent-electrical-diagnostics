# Эксперименты

Фиксировать воспроизводимые эксперименты по разбору электрических схем и диагностическим сценариям.

Для каждого эксперимента сохранять: версию входной схемы, версию модели, используемый сценарий, входные факты, выбранные ядром проверки, результаты, итог, эталонную оценку специалиста и обнаруженные ограничения.
