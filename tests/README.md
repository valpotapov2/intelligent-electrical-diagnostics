# Проверки

Планируемые проверки:
- валидность структуры JSON;
- уникальность идентификаторов компонентов;
- корректность ссылок соединений;
- единицы измерения и типы значений;
- сохранение provenance и confidence;
- обнаружение неразрешённых связей;
- сверка итогов мощностей и токов с таблицами схемы;
- сценарная достаточность модели;
- запрет опасных действий через SafetyGateway.

Проверки должны различать ошибку распознавания, противоречие источника и неизвестный параметр.
