# Intelligent Electrical Diagnostics

Проект интеллектуальной диагностики электрооборудования. Основной пользовательский принцип: электрик загружает электрическую схему; система автоматически извлекает сведения, строит частичную модель и задаёт только необходимые уточняющие вопросы.

## OCR ingestion MVP

Первый исполняемый прототип находится в `src/edi_ingest`.

### Возможности

- PDF и растровые изображения;
- OCR через Tesseract;
- сохранение распознанных токенов, координат и confidence;
- поиск обозначений QF, KM, TA, шин L1/L2/L3/N/PE и АВР;
- создание чернового JSON с provenance;
- выделение кандидатов горизонтальных/вертикальных линий и пересечений средствами OpenCV;
- выделение замкнутых геометрических форм-кандидатов с фильтрацией областей OCR-текста.

Геометрические сегменты и пересечения — только кандидаты. Они пока не означают подтверждённые электрические соединения. Для PDF дополнительно сохраняются нативные векторные отрезки и прямоугольники в координатах PDF; они также не классифицируются автоматически как провода или аппараты.

**Важно:** распознавание геометрических форм не является распознаванием электрических символов. Круг или прямоугольник не получает тип аппарата, выводы или электрический смысл. Текущий MVP не восстанавливает электрические соединения и не является готовым парсером электрических схем.

### Установка

Нужен установленный Tesseract OCR и языковые данные для русского и английского языков.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Пример для Debian/Ubuntu:

```bash
sudo apt-get install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
```

### Запуск

```bash
edi-ingest path/to/diagram.pdf --object-name "Kindergarten switchboard" -o model.draft.json --ocr-output ocr.json
```

Для изображения:

```bash
edi-ingest path/to/diagram.png --lang rus+eng -o model.draft.json
```

### Тесты

```bash
pytest
```
