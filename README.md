# Intelligent Electrical Diagnostics

Проект интеллектуальной диагностики электрооборудования на основе специализированного диагностического ядра.

## Основной принцип

**Для начала работы электрик предоставляет электрическую схему.** Система самостоятельно извлекает из неё структуру объекта, строит предварительную цифровую модель, отмечает неизвестные и неоднозначные данные и запрашивает у специалиста только те уточнения, которые необходимы для конкретного диагностического шага.

Не требовать от электрика предварительного заполнения подробной анкеты или ручного построения полной модели щита.

## Первый пилот

Первый объект — распределительный щит детского сада. Исходные сведения и предварительная модель находятся в [models/switchboards/kindergarten](models/switchboards/kindergarten/).

Модель получена визуальным разбором предоставленной растровой однолинейной схемы и пользовательских пояснений. Это черновая проектная модель, не исполнительная документация и не подтверждение фактического монтажа.

## Принципы качества

- Не додумывать неразборчивые обозначения, связи и характеристики.
- Хранить происхождение каждого извлечённого значения и уверенность распознавания.
- Разделять проектную схему и фактическое состояние объекта.
- Разрешать частичную модель и явно учитывать неизвестные параметры.
- Запрашивать дополнительные сведения только по необходимости конкретной проверки.
- Не выдавать диагностическую гипотезу за подтверждённый диагноз.
- Работы внутри электрощита и измерения на токоведущих частях выполняются только квалифицированным персоналом с соблюдением требований электробезопасности.

## Статус

Начальный этап: извлечение структуры из схемы и формирование машинно-читаемой модели. Следующий этап — проверка распознавания и подготовка виртуальных диагностических сценариев.

## Структура

- `docs/architecture/` — архитектурные принципы.
- `docs/pilot/` — план и критерии пилота.
- `docs/safety/` — границы безопасного применения.
- `models/switchboards/` — модели объектов.
- `diagnostics/scenarios/` — диагностические сценарии.
- `schema/` — форматы данных.
- `tests/` — проверки моделей и логики.
- `experiments/` — результаты экспериментов.
