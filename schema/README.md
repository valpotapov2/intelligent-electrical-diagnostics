# Форматы данных

Здесь будут храниться схемы машинно-читаемых моделей электрообъектов, компонентов, соединений, происхождения данных, неопределённостей и диагностических сценариев.

Текущая модель электрощита — черновик версии 0.1. Перед фиксацией стабильной JSON Schema необходимо проверить структуру на нескольких реальных схемах и не закреплять преждевременно спорные предположения.
