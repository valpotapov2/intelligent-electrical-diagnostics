# Электрощит детского сада — модель 0.1-draft

Модель получена по растровой однолинейной схеме и пояснениям пользователя.

Файлы:
- `model.json` — машинно-читаемая предварительная модель;
- `outgoing-groups.csv` — таблица отходящих групп;
- `open-issues.md` — список неоднозначностей.

Это проектная модель по схеме, не исполнительная документация и не подтверждение фактического монтажа. Не использовать для реальных коммутаций или работ без проверки квалифицированным специалистом.
