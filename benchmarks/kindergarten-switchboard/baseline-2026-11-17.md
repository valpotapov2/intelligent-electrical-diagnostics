# Kindergarten switchboard — first real-image baseline

## Source image

- Original file: `1000055928.jpg` (from the user-provided conversation attachment)
- Raster size: 1536 × 1109 px
- Format: JPEG
- The source image is not committed to this repository yet. This report records the dimensions and results from the attached source; it does not claim the repository contains the image.

## Run conditions

The source was processed locally with the same core algorithms/configuration currently present in `main`:

- Tesseract 5.5.0, languages `rus+eng`.
- Whole-page OCR with `--psm 11` (the ingestion default).
- Comparison OCR with `--psm 6` and `--psm 12`.
- Incoming-device detail crop: source rectangle `[990, 35, 1380, 330]`, enlarged 3×, OCR `--psm 6`.
- Geometry preprocessing: grayscale, adaptive mean threshold, binary inverse, block size 31, C=12.
- Morphological horizontal/vertical kernels follow `geometry.py` (page-width scale factor 1 for this image).
- HoughLinesP: rho=1, theta=1 degree, threshold=17, minLineLength=35, maxLineGap=8.
- Closed contour descriptors follow `symbols.py`: min area 90 px², max area 4% page area, minimum bbox dimensions 8×8, polygon approximation epsilon 3.5% perimeter.

This is a local baseline run of the repository's current algorithms/configuration, not a claim that a packaged `edi-ingest` CLI run was executed from a checked-out working tree.

## Results

### OCR

| Setting | Non-empty tokens | Equipment-reference regex hits |
|---|---:|---|
| PSM 11 (default) | 200 | KM2 and PE only |
| PSM 6 | 305 | no exact QF/KM/TA/ATS/bus-label regex hits |
| PSM 12 | 206 | no exact QF/KM/TA/ATS/bus-label regex hits |

For PSM 11, 98 of 200 non-empty tokens had Tesseract confidence >= 50. This is a count, not an accuracy score.

The 3× incoming-device crop recovered more legible fragments:
- `1QF` / `2QF` are rendered imperfectly (OCR output: `10F`, `20F`).
- `3C200` was read as `3€200`.
- `BA88-35` was read approximately as `888-35` / `ВАВ8-35`.
- `35kA` was readable.
- `KM1` was imperfect; `KM2` was legible.
- `АВР` was read.
- Meter and CT text was only partly recovered.

Interpretation: whole-page OCR is not sufficient for reliable equipment-tag extraction on this scan. Region proposals/crops and OCR tuned by region are needed before changing the semantic recognizer.

### Geometry

Raw Hough output before the repository's segment merge:
- horizontal line fragments: 232
- vertical line fragments: 256

Closed-contour candidates before OCR-overlap suppression and nested-contour suppression:
- total: 331
- rectangular outlines: 120
- polygonal outlines: 151
- circular outlines: 19
- quadrilateral outlines: 18
- irregular closed shapes: 23

These are intermediate counts, not final `edi-ingest` output counts. They include table borders, drawing frame, text artifacts and non-electrical graphics. They must not be reported as counts of wires, junctions or electrical components.

## Conclusions supported by this run

1. The scan is processable by the current OCR and CV dependencies.
2. Whole-page OCR has weak exact recall for the equipment tags that matter in this drawing.
3. Enlarging the incoming-device region improves legibility, but several strings remain confused.
4. Geometry produces many candidates, and most cannot be assigned electrical meaning from shape alone.
5. The next useful engineering step is ROI (region of interest) detection and region-specific OCR, with the load table and equipment clusters handled separately.

## Not measured yet

- OCR precision/recall against a reviewed transcription.
- Symbol candidate precision/recall.
- Final merged line-segment and shape counts from a complete CLI output.
- Junction correctness, terminal attachment, wire tracing or net identity.
- Any safety/diagnostic conclusion about the actual switchboard.

2. runs the exact `ingest_document` and `build_model` functions;

4. emits crop images for low-confidence equipment/table regions;
5. compares reviewed ground truth to extracted candidates and reports per-class precision/recall.

Do not implement automatic electrical topology inference until the benchmark has reviewed coordinate annotations.
