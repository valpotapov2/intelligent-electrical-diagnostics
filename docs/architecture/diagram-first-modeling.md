# Модель объекта по электрической схеме

## Цель

Свести к минимуму трудозатраты электрика на подготовку диагностики. Единственный обязательный входной материал для старта — электрическая схема в доступном формате (PDF, изображение или экспорт проекта).

## Конвейер

1. Приём схемы и сохранение исходного документа.
2. Извлечение графических и текстовых элементов: аппараты, обозначения, номиналы, шины, линии, соединения, нагрузки.
3. Построение графа электрической структуры.
4. Нормализация типов компонентов и атрибутов.
5. Сохранение ссылок на источник: страница, область изображения, исходная надпись.
6. Оценка уверенности распознавания.
7. Проверка структурной согласованности и выявление противоречий.
8. Передача частичной модели диагностическому ядру.

## Правила

- Отсутствующее значение остаётся неизвестным, а не заполняется типовым значением.
- Неоднозначная связь сохраняется как unresolved relation.
- Проектная схема не считается доказательством фактического монтажа.
- Расхождения между схемой, спецификацией и фактом регистрируются отдельно.
- Модель может быть неполной; полнота оценивается относительно конкретного диагностического сценария.
- Дополнительный вопрос специалисту формируется только тогда, когда неизвестное препятствует безопасному и обоснованному следующему шагу.

## Достаточность данных

Не существует одного универсального процента полноты для всех задач. Система должна проверять достаточность модели для конкретной гипотезы и конкретной проверки: известны ли нужные участок цепи, тип аппарата, параметры, условия измерения и ограничения безопасности.

## Формат модели

Машинно-читаемая модель должна хранить:
- объект и исходные документы;
- компоненты и их типы;
- электрические соединения и принадлежность линий;
- атрибуты и единицы измерения;
- происхождение каждого атрибута;
- confidence / статус проверки;
- неизвестные данные и противоречия;
- связь с диагностическими сценариями.
